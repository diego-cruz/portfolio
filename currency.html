Currency — Design System for NerdWallet SMB

I created Currency from scratch to bring NerdWallet’s visual identity to the SMB team’s products, which originated at Fundera. Using NerdWallet’s branding as a reference, I designed all the visuals and structured the component library in Figma.

Role
Design system creator
Platforms
Web & mobile web
My scope
All visual design and Figma library creation, with contributions from two designers through brainstorming, feedback, and updates.
The challenge

From Fundera’s identity to NerdWallet’s brand

The SMB team’s existing assets reflected Fundera’s visual identity, which was significantly different from NerdWallet’s. The goal was to bring NerdWallet’s visual language into the team’s products through a reusable design system.

Ownership & collaboration

Created from scratch, with feedback along the way

I was responsible for creating Currency, including all its visual design and the Figma library. NerdWallet’s branding provided the reference for the visual direction.

I worked independently on the creation, with contributions from two other designers through brainstorming, feedback, and updates.

Inside Currency

A library organized for SMB product design

The library brings together visual foundations and component categories for web and mobile web.

Foundations

Spacing, typography, grids, shadows, and elevation form the visual foundation of the library.

Components

The library is organized into Action, Display, Layout, Navigation, and Overlay categories, alongside Assets.

Brand alignment

Currency brings NerdWallet’s branding into the visual assets created for the SMB team.
